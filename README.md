# 🖱️ Horizontal Scroll with Arrows

This is a small JavaScript project that enables **horizontal scrolling** through a content area (such as images or cards) using **left and right arrow buttons**.

---

## 🚀 Features

- ▶️ Scroll right and left with custom arrow buttons
- 🖼 Works with any horizontally scrollable content (images, cards, etc.)
- ⚙️ Smooth scroll behavior using JavaScript
- 📱 Responsive and user-friendly

---

## 🛠️ Technologies Used

- **HTML** – Structure of the scroll container and buttons
- **CSS** – Styling and layout (including scroll behavior)
- **JavaScript** – Scroll logic using `scrollLeft`

---

## 💻 How It Works

1. A scrollable container holds several items side by side (e.g. images, divs).
2. Two arrow buttons (`←` and `→`) are placed on the sides.
3. When the user clicks the arrows:
   - JavaScript adds/subtracts from `scrollLeft` to scroll the container.
   - Scrolling is smooth and can be customized.
